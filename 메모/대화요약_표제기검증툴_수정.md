## 프로젝트 현황

- `index.html` — 표제기 자동 검증 웹앱 (HTML+Vanilla JS 단일 파일, ~216KB)
- `의약품_표준제조기준.json` — 표제기 원본 데이터 (5개 장: 제1장 비타민미네랄, 제2장 해열진통제, 제3장 감기약, 제7장 진해거담제, 제9장 비염용경구제)
- JSON 데이터는 index.html 내부에 `__EMBEDDED_DB__` 변수로도 임베딩되어 있음
- 기존에 성분 검색 버그(수정1), 용법용량 범위 입력(수정2), 결과 테이블 상세화(수정3)는 이전 프롬프트(`클로드코드_수정요청_프롬프트.md`)로 수정 완료

## 이번 대화에서 발견한 버그 및 수정 요청 사항 (3건)

### 버그1: 효능효과 기본 문구(세부항목) 누락

**증상**: 제1장 비타민미네랄에서 효능효과 자동생성 시, "다음경우의 비타민 X의 보급" + "육체피로", "임신·수유기" 등 기본 문구가 전혀 출력되지 않음

**원인 분석**:
- `generateEfficacy()` 함수의 제1장 분기에서 `effData['기본기재']`와 `effData['세부항목']`을 전혀 사용하지 않고 있음
- 코드는 `1일_보급량_기준_기재조건` (비타민A 2000IU 이상 등)과 `표6_효능효과`만 참조
- JSON 구조:
  ```
  기준 → 효능효과 → 기본기재: "다음경우의 비타민 X(X : A, D, E, B1, B2, B6, C)의 보급"
  기준 → 효능효과 → 세부항목: ["육체피로(비타민 B1, B2, C 함유시)", "임신·수유기(비타민 D, B1, B2, B6, C 함유시)", ...]
  ```

**수정 방향**:
- 세부항목의 괄호 안 조건(비타민 B1, B2, C 함유시)을 파싱
- activeRows 성분이 표1_비타민의 어떤 비타민에 속하는지 `extractVitType()` 함수로 판단
- 조건 비타민 중 하나라도 포함되면 해당 세부항목 ok
- 기본기재 문구의 "X"를 실제 포함된 비타민 목록으로 치환

**참고 — effData 경로 수정은 이미 완료됨**:
- 이전에 `kijun['1일_보급량_기준_기재조건']` → `effData['1일_보급량_기준_기재조건']`로 수정 적용됨 (line 2196~2198)
- `const effData = kijun['효능효과'] ?? {};` 이미 들어가 있음

### 수정2: 배합량 검증 테이블에 "기재가능 효능효과" 컬럼 추가

**현재 테이블 컬럼** (`renderChapter1Results()`, line 1282~):
| 성분명 | 1캡슐당 | 1일 최소 | 1일 최대 | 기준 최소 | 기준 최대 | 판정 |

**추가 요청**:
- "기재가능 효능효과" 컬럼을 오른쪽에 추가
- 해당 성분의 1일 최대 배합량이 기재조건 이상이면 → 효능효과 문구 표시
  - 예: 비타민A 1일 최대 9000IU ≥ 2000IU → "눈의 건조감의 완화, 야맹증"
- 미충족 시 회색으로 "조건 미충족 (기준: 2,000 IU 이상)" 표시

**데이터 참조 경로**:
- 비타민: `DB['제1장_비타민미네랄']['표']['표6_효능효과']` → `{ 제제: "비타민A함유제제", 효능효과: [...] }`
- 기재조건: `DB['제1장_비타민미네랄']['기준']['효능효과']['1일_보급량_기준_기재조건']` → `{ 성분: "비타민A", 기재조건: "2,000 IU 이상일 때" }`
- 미네랄 추가효능: `DB['제1장_비타민미네랄']['기준']['효능효과']['추가효능']`

### 수정3: 사용상 주의사항 — 카테고리 제목을 표제기 원문 그대로 + 순번

**현재 문제**:
- CAT_LABELS에 약칭 + 이모지 사용: `['복용하지_말_것', '🚫 복용하지 말 것']`
- 표준제조기준 원문대로 기재해야 함

**수정할 CAT_LABELS**:
```javascript
const CAT_LABELS = [
  ['경고',                   '경고'],
  ['복용하지_말_것',         '다음과 같은 사람은 이 약을 복용하지 말 것'],
  ['병용금기',               '이 약을 복용하는 동안 다음의 약을 복용하지 말 것'],
  ['복용전_상의',            '다음과 같은 사람은 이 약을 복용하기 전에 의사, 약사와 상의할 것'],
  ['이상반응_및_즉각중지',   '복용을 즉각 중지하고 의사 또는 약사와 상의할 것. 또한 다음의 경우에는 그 증상이 지속되거나 증가할 경우에도 의사 또는 약사와 상의할 것'],
  ['기타주의사항',           '기타 주의사항'],

  ['복용시_주의',            '복용 시 주의사항'],
  ['저장상의_주의',          '저장상의 주의사항'],

```

**번호 체계**:
- 제목: `1. 경고`, `2. 다음과 같은 사람은 이 약을 복용하지 말 것` (sections.map에서 secIdx + 1)
- 하위 항목: `1) xxx`, `2) xxx` (items.map에서 idx + 1, 마침표 대신 닫는 괄호)
