# Claude Code 수정 요청 프롬프트

> 아래 프롬프트를 Claude Code에 **그대로 복사-붙여넣기** 하세요.
> 3건을 한 번에 요청하여 토큰을 절약합니다.

---

```
index.html의 제1장(비타민미네랄) 검증 로직을 3가지 수정해줘.
기존 코드 구조와 스타일을 유지하면서 수정해.

■ 수정1: 성분 검색 실패 버그 수정
- 현재 γ-오리자놀 등 표3_기타성분의 성분이 "표1~표4에서 찾을 수 없다"고 나옴
- 근본 원인: JSON 데이터에서 표마다 "성분명" 필드의 타입이 다름
  · 표1_비타민: 성분명이 배열(array) → ["레티놀아세테이트...", ...]
  · 표2_미네랄: 성분명이 문자열(string) → "칼슘으로서"
  · 표3_기타성분: 성분명이 배열(array) → ["γ-오리자놀"]
  · 표4_생약: 성분명이 배열(array) → ["인삼", "홍삼", ...]
- 해결 방법:
  1. 성분 검색 함수에서 성분명이 배열인 경우와 문자열인 경우를 모두 처리
     → Array.isArray(item.성분명) ? item.성분명.some(n => 매칭) : item.성분명 매칭
  2. 추가로 JSON 데이터(const DATA)의 그리스 문자 성분명도 한글로 통일:
     → "γ-오리자놀" → "감마오리자놀"
     → "α-토코페롤" 등 그리스 문자가 포함된 성분은 모두 한글로 변경
     (JSON의 const DATA 변수 안에서 직접 수정)
  3. 표2_미네랄의 성분명도 배열 형태로 통일하면 더 좋음
     → "칼슘으로서" → ["칼슘으로서"]

■ 수정2: 용법용량 입력을 "범위"로 변경
- 현재: 1일 횟수, 1회 복용량이 고정값 드롭다운
- 변경: 범위 입력 방식으로 수정
- UI 구성:
  · 1일 복용횟수: [최소 ▼] ~ [최대 ▼] 회 (드롭다운, 선택지: 1,2,3)
  · 1회 복용량: [최소 ▼] ~ [최대 ▼] 캡슐/정/포 (드롭다운, 선택지: 1,2,3)
  · 예시: "1일 1~3회, 1회 1~2캡슐"
- 계산 로직:
  · 사용자가 각 성분의 "1캡슐(또는 1정/1포)당 배합량"을 입력
  · 1일 최소 배합량 = 1캡슐당 배합량 × 1회 최소 복용량 × 1일 최소 횟수
  · 1일 최대 배합량 = 1캡슐당 배합량 × 1회 최대 복용량 × 1일 최대 횟수
  · 예: 1캡슐당 100mg, 1회 1~2캡슐, 1일 1~3회
    → 1일 최소 = 100×1×1 = 100mg
    → 1일 최대 = 100×2×3 = 600mg

■ 수정3: 결과 화면에 1일 최소/최대 함량 비교 표시
- 현재: 한 줄로 계산 결과만 표시
- 변경: 표(table) 형태로 상세 비교 표시
- 결과 테이블 컬럼:
  | 성분명 | 1캡슐당 | 1일 최소 배합량 | 1일 최대 배합량 | 기준 1일 최소 | 기준 1일 최대 | 판정 |
- 기준 계산 (★ 표마다 다르게 처리 — 중요):
  · 표1_비타민: "1일최소분량"과 "1일최대분량" 필드가 둘 다 있음 → 각각 그대로 사용
  · 표2_미네랄, 표3_기타성분, 표4_생약: "1일최대분량"만 있고 최소 없음
    → 기준 1일 최대 = JSON의 "1일최대분량" 값
    → 기준 1일 최소 = 없음 (최소 기준 검증 안 함, "-" 또는 "해당없음"으로 표시)
  · ★ 절대로 "최대 ÷ 2 = 최소"로 계산하지 말 것! 표2~표4는 최소 기준 자체가 없음
- 판정 로직:
  · 표1(비타민): 기준최소 ≤ 1일최소배합량 AND 1일최대배합량 ≤ 기준최대 → "적합(O)"
  · 표2~표4: 1일최대배합량 ≤ 기준최대 → "적합(O)" (최소 기준 없으므로 최대만 검증)
  · 부적합 시 사유 표시 (예: "1일 최대 초과")
- 단위 자동 환산:
  · 환산 규칙: 1mg = 1000μg, 1g = 1000mg
  · 기준 단위와 입력 단위가 다르면 자동 환산 후 비교
  · 환산 적용 시 "(자동환산)" 표시
  · IU는 IU끼리만 비교 (단위 불일치 시 "단위확인필요" 표시)

3가지 수정 후 제1장 전체가 정상 동작하는지 테스트해줘.
특히 다음 케이스를 확인:
1. 감마오리자놀 검색 → 표3_기타성분에서 찾아야 함, 1일최대 10mg, 기준최소는 "-"(없음)
2. 콘드로이틴설페이트나트륨 → 표3, 1일최대 600mg, 기준최소는 "-"(없음). 300mg이 최소로 나오면 버그임!
3. 비타민A(레티놀아세테이트) → 표1, 기준최소 500IU, 기준최대 10000IU (표1만 최소 있음)
4. 칼슘 검색 → 표2_미네랄에서 찾아야 함, 기준최소는 "-"(없음)
4. 용법용량 1일 1~3회, 1회 1~2캡슐 설정 후 배합량 입력 → 최소/최대 정상 계산
5. 비타민A 1캡슐당 3000IU, 1일 1~3회, 1회 1캡슐 → 1일 최소 3000IU, 1일 최대 9000IU → 기준 최대 10000IU → 적합
```
