# Claude Code 수정 요청 프롬프트 (효능효과 기본문구 + 검증표 통합 + 사용상 주의사항)

```
index.html에서 3가지를 수정해줘.
기존 코드 구조와 스타일을 유지하면서 수정해.

■ 수정1: 효능효과 자동생성 — 기본 문구(세부항목) 누락 수정

현재 상태:
- 제1장 비타민미네랄의 효능효과 자동생성 결과에서 "기본 문구"가 전혀 출력되지 않음
- JSON 데이터에는 아래 내용이 있는데 코드가 이걸 사용하지 않고 있음:
  · 기준.효능효과.기본기재: "다음경우의 비타민 X(X : A, D, E, B1, B2, B6, C)의 보급"
  · 기준.효능효과.세부항목: ["육체피로(비타민 B1, B2, C 함유시)", "임신·수유기(비타민 D, B1, B2, B6, C 함유시)", "병중·병후의 체력저하시(비타민 A, B1, B2, B6, C 함유시)", "발육기(비타민 D 함유시)", "노년기(간유, 비타민 D, E 함유시)"]

수정 방법:
- generateEfficacy() 함수의 제1장_비타민미네랄 분기 안에서:
  1. effData(= kijun['효능효과'])에서 '기본기재'와 '세부항목'을 꺼냄
  2. 세부항목 각각에 대해, 괄호 안의 조건(비타민 B1, B2, C 함유시 등)을 파싱
  3. 사용자가 입력한 activeRows 성분과 대조하여, 해당 비타민이 포함되어 있으면 ok: true
  4. 기본기재 문구에서 "X"를 실제 포함된 비타민 목록으로 치환하여 최종 문구 생성
     → 예: 비타민 B1, C가 포함되면 "다음경우의 비타민 B1, C의 보급"
  5. items 배열의 맨 앞에 이 기본 문구 + 세부항목 결과를 추가

세부항목 파싱 로직:
  - "육체피로(비타민 B1, B2, C 함유시)" → label: "육체피로", 조건 비타민: [B1, B2, C]
  - 조건의 비타민 중 하나라도 activeRows에 포함되면 ok: true
  - "간유"는 표1_비타민의 성분명에 "간유"가 포함된 성분이 있는지로 판단
  - ok인 세부항목만 최종 효능효과 문구에 포함

비타민 포함 여부 판단:
  - activeRows의 각 성분이 표1_비타민에서 어떤 항목(Ⅰ(비타민A) 등)에 속하는지 확인
  - extractVitType() 함수를 재활용하면 됨 (이미 존재함)
  - 예: 레티놀팔미테이트 → 표1에서 항목 "Ⅰ(비타민A)" → 비타민A

결과 표시 (renderEfficacy에도 반영):
  - 기본 문구 영역을 items 테이블 위에 별도 박스로 표시:
    ① 기본기재 문구 (비타민 목록 치환된 버전)
    ② 세부항목 중 ok인 것들 나열
  - 기존의 "1일_보급량_기준_기재조건" 기반 효능효과(표6)는 그 아래에 그대로 유지


■ 수정2: 배합량 검증 결과 테이블에 "기재가능 효능효과" 컬럼 추가

현재 상태:
- renderChapter1Results()의 검증 테이블 컬럼:
  | 성분명 | 1캡슐당 | 1일 최소 | 1일 최대 | 기준 최소 | 기준 최대 | 판정 |
- 여기에 "기재가능 효능효과" 컬럼을 추가하고 싶음

수정 방법:
1. validateChapter1() 함수에서 각 itemResult를 만들 때, 해당 성분이 속한 비타민/미네랄의
   효능효과 기재 조건을 함께 계산
   - 예: 레티놀팔미테이트 → 비타민A → 1일 보급량 2,000 IU 이상이면
     → 표6_효능효과에서 "비타민A함유제제"의 효능효과: ["눈의 건조감의 완화", "야맹증(밤에 잘 못보는 증상)"]
   - 1일 최대 배합량이 기재조건 이상이면 → 해당 효능효과 문구를 itemResult에 추가
   - 기재조건 미만이면 → "(미충족)" 표시

2. renderChapter1Results() 테이블에 컬럼 추가:
   - 헤더: <th>기재가능 효능효과</th>
   - 셀 내용: 해당 성분의 1일 최대 배합량이 기재조건 충족 시 효능효과 문구 표시
   - 미충족 시: 회색 텍스트로 "조건 미충족 (기준: 2,000 IU 이상)" 등 표시
   - 표2~표4 성분(미네랄, 기타, 생약): 추가효능 조건으로 동일하게 처리

데이터 참조 경로:
  - 비타민 효능효과: DB['제1장_비타민미네랄']['표']['표6_효능효과'] 배열
    · 각 행: { 제제: "비타민A함유제제", 효능효과: ["눈의 건조감의 완화", ...] }
  - 기재조건: DB['제1장_비타민미네랄']['기준']['효능효과']['1일_보급량_기준_기재조건'] 배열
    · 각 행: { 성분: "비타민A", 기재조건: "2,000 IU 이상일 때" }
  - 미네랄 추가효능: DB['제1장_비타민미네랄']['기준']['효능효과']['추가효능'] 배열
    · 예: "칼슘결핍 및 기타 칼슘의 보급(칼슘으로서 300 mg이상일 때)"

비타민↔성분 매핑:
  - 표1_비타민의 항목 필드에서 extractVitType()으로 비타민명 추출
  - 예: 항목 "Ⅰ(비타민A)" → "비타민A"
  - activeRow의 성분이 해당 비타민 항목에 속하면 → 그 비타민의 기재조건과 효능효과를 적용


■ 수정3: 사용상 주의사항 — 카테고리 제목을 표제기 원문 그대로 + 제목 번호 부여

현재 상태:
- CAT_LABELS 배열에서 카테고리 제목이 약칭으로 되어있음:
  ['복용하지_말_것', '🚫 복용하지 말 것']
  ['병용금기', '🔗 병용금기']
  ['복용전_상의', '🩺 복용 전 상의']
  등등

- 이걸 의약품 표준제조기준 표제기의 실제 원문 제목으로 변경해야 함
- 그리고 제목 앞에 순번(1, 2, 3...)도 붙여야 함

수정 방법 — CAT_LABELS 배열을 아래로 교체:

  const CAT_LABELS = [
    ['경고',                   '경고'],
    ['복용하지_말_것',         '다음과 같은 사람은 이 약을 복용하지 말 것'],
    ['병용금기',               '이 약을 복용하는 동안 다음의 약을 복용하지 말 것'],
    ['복용전_상의',            '다음과 같은 사람은 이 약을 복용하기 전에 의사, 약사와 상의할 것'],
    ['이상반응_및_즉각중지',   '복용을 즉각 중지하고 의사 또는 약사와 상의할 것. 또한 다음의 경우에는 그 증상이 지속되거나 증가할 경우에도 의사 또는 약사와 상의할 것'],
    ['기타주의사항',           '기타 주의사항'],
    ['소아투여',               '소아에 대한 투여'],
    ['복용시_주의',            '복용 시 주의사항'],
    ['저장상의_주의',          '저장상의 주의사항'],
  ];

그리고 renderPrecautions()에서 제목 표시 부분도 수정:

- 현재 코드:
  sections.map(sec => { ... ${sec.label} ... })
  → sec.label만 표시

- 수정: sections.map()에서 index를 활용하여 순번 추가
  sections.map((sec, secIdx) => { ... ${secIdx + 1}. ${sec.label} ... })

- 이모지(⚠️, 🚫, 🔗 등) 제거 — 원문에는 이모지가 없음
- 제목 스타일: 기존 빨간색 bold 유지하되, 이모지 없이 "1. 경고", "2. 다음과 같은 사람은..." 형태

또한 항목 내 번호(하위 항목)도 유지:
- 각 카테고리 안의 개별 항목에 1), 2), 3) 순번 (현재 이미 적용된 idx+1 로직 유지)
- 형태: "1) 텍스트", "2) 텍스트" (마침표 대신 닫는 괄호 사용 → 제목 번호와 구분)

정리하면:
  제목: "1. 경고", "2. 다음과 같은 사람은 이 약을 복용하지 말 것"
  하위 항목: "1) 고칼슘혈증 환자...", "2) 이 약 및 이 약에 포함된..."


수정 완료 후 확인 테스트:
1. 제1장 비타민미네랄 → 레티놀팔미테이트 3000IU + 티아민질산염(비타민B1) 30mg 입력
   → 1일 1~3회, 1회 1캡슐
   → 효능효과 기본문구: "다음경우의 비타민 A, B1의 보급" 표시되어야 함
   → 세부항목: "육체피로" (B1 포함이므로 ok), "병중·병후의 체력저하시" (A, B1 포함이므로 ok) 등
   → 검증 테이블: 레티놀팔미테이트 행에 "눈의 건조감의 완화, 야맹증" 표시 (1일 최대 9000IU ≥ 2000IU)
   → 티아민질산염 행에 "다음 증상의 완화: 신경통, 근육통..." 표시 (1일 최대 90mg ≥ 25mg)

2. 사용상 주의사항:
   → 제목이 "1. 경고", "2. 다음과 같은 사람은 이 약을 복용하지 말 것" 형태
   → 이모지(⚠️🚫🔗 등) 없음
   → 하위 항목은 "1) xxx", "2) xxx" 형태
   → "복용하지 말 것"으로 축약되면 실패!
```
