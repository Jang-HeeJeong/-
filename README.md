# 의약품 표준제조기준 검토 툴

의약품 허가사항이 식약처 **표준제조기준**(고시 제2025-3호)에 맞는지 검토하는 웹 도구입니다.
성분과 배합량을 넣으면 적합/부적합을 판정하고, 효능효과와 사용상 주의사항 문구를 자동으로 만들어 줍니다.

| | 주소 |
|---|---|
| **검토 툴** | https://jang-heejeong.github.io/-/ |
| 테스트 확인 | https://jang-heejeong.github.io/-/tests.html |
| 새 UI (작업 중) | https://jang-heejeong.github.io/-/new.html |

---

## 파일 구성

```
📄 index.html                    검토 툴 화면 ← 사이트 첫 페이지
📄 new.html                      새 UI 작업본 (완성되면 index.html과 교체)

📁 app/                          프로그램 본체
   📄 표제기_데이터.js            ★ 성분·분량·연령계수 데이터
   📄 판정_규칙.js                ★ 적합/부적합 판정 로직

📄 개정_반영_가이드.md            ★ 고시가 개정됐을 때 볼 문서
📄 디자인_가이드.md               화면 디자인 규칙 (Vercel 스타일)

📄 tests.html                    테스트 실행 화면
📁 tests/                        테스트 재료
   📄 cases.js                     검사할 제품 목록
   📄 baseline.js                  정답으로 삼는 기준값
   📄 flows.js                     화면 전환 검사 항목
   📄 README.md                    테스트 사용법
```

★ 표시가 **개정할 때 손대는 파일**입니다.

## 표제기가 개정되면

**[개정_반영_가이드.md](개정_반영_가이드.md)** 를 보세요. 어디를 고치는지 표로 정리돼 있습니다.

요약하면 이렇습니다.

| 바뀐 내용 | 고칠 파일 |
|---|---|
| 성분 추가·삭제, 1일 분량 변경, 연령계수 | `app/표제기_데이터.js` |
| 배합 규칙, 연령 구분, 특수 성분 제한 | `app/판정_규칙.js` |
| 화면 | `index.html` (개정 때는 거의 안 건드림) |

고친 뒤에는 **반드시 테스트를 돌려** 의도한 항목만 바뀌었는지 확인하세요.

## 고친 내용을 사이트에 올리려면

```bash
git add .
git commit -m "무엇을 고쳤는지 한 줄로"
git push
```

1~2분 뒤 사이트에 반영됩니다. 브랜치는 `main` 하나뿐이라 이름을 쓸 필요가 없습니다.

---

## 테스트

코드를 고친 뒤 **판정 결과가 의도치 않게 바뀌지 않았는지** 확인하는 안전망입니다. 현재 49건.

`tests.html`을 열면 자동으로 실행됩니다. (사이트 주소로 열어도 되고, 로컬에서 확인하려면 아래)

```bash
python -m http.server 7777
```
→ `http://localhost:7777/tests.html`

| 결과 | 뜻 |
|---|---|
| 통과 | 판정이 이전과 같음 |
| **실패** | 판정이 바뀜 → 의도한 변경인지 확인. 아니면 **버그** |
| 오류 | 코드가 깨졌거나 성분명이 표에 없음 |

자세한 사용법은 [tests/README.md](tests/README.md) 참고.

## 알아둘 점

**빌드 도구가 필요 없습니다.** Node.js·npm 없이 파일만 있으면 브라우저에서 바로 돌아갑니다.
`app/표제기_데이터.js`가 `.json`이 아니라 `.js`인 것도 이 때문입니다.

**화면에 없는 장의 데이터가 이미 들어 있습니다.**
현재 툴은 제1·2·3·7·9장을 다루지만, 데이터 파일에는 제4·5·6·8·10~14장도 들어 있습니다.
나중에 장을 늘릴 때 데이터를 새로 만들 필요는 없습니다.

**허가목록**(제품 검색에 쓰이는 150개 품목)은 표준제조기준과 별개입니다.
화면 상단 📂 버튼으로 최신 엑셀을 올려 갱신합니다.
